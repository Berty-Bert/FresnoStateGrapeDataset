# Fresno State Grape Dataset

This repository contains real vineyard images and artificially generated
grape images used for research on grape detection and synthetic-to-real
domain adaptation. Each image is provided with a corresponding ground-truth
segmentation mask identifying the grape regions.
The dataset includes images collected
by the authors as well as a subset of images from the Embrapa Wine Grape
Instance Segmentation Dataset (WGISD).
